# Imagine classifier production baseline

The production Imagine classifier serves the **Qwen3.8-27B Q4_K_M GGUF** through the default backend and private predictor routes. The live classification-only web bundle calls the untagged public API. The selected NF4-plus-adapter checkpoint was the training source; it is not the serving format. The [2026-10-22 cutover receipt](../experiments/imagine-27b-default-cutover-20261022.json) pins the deployed revisions, container digests, Hugging Face revision, Hosting version, smoke results, and confirmed 4B cleanup.

The shared 64-image validation cohort scored **43/64** exact for NF4 plus adapter, **40/64** for merged BF16, and **37/64** for the corrected GGUF route. The separate 181/250 final assessment belongs only to NF4 plus adapter. See the [matched benchmark workflow](RUNPOD-INFERENCE-BENCHMARK.md) and the [GGUF](RUNPOD-GGUF-BENCHMARK-20261004.md) and [BF16](RUNPOD-BF16-BENCHMARK-20261005.md) run records.

The public model is [`christian-bick/EduGraph-Classifier-Qwen3.8-27B-GGUF` at revision `477e3caf32eced2a9e002ead1edccc9a5c458f0c`](https://huggingface.co/christian-bick/EduGraph-Classifier-Qwen3.8-27B-GGUF/tree/477e3caf32eced2a9e002ead1edccc9a5c458f0c), released under Apache-2.0. The 27B default backend is `imagine-server-27b-default-d8813a5`; its untagged private predictor is `edugraph-predict-00006-nej`. The exact tested Firebase Hosting version `sites/imagine-web/versions/5478bb45b1ea67b5` is live at `https://demo.edugraph.io`. Built-in and pinned validation-image uploads passed both the tagged canary and default backend checks, then the hosted live flow. A 27B canary remains for smoke tests. Confirmed 4B traffic tags and runtime resources were removed; unclassified historical backend entries remain retained for provenance, as the [cleanup record](GCP-CLEANUP.md) explains.

For a future release, follow the [model-to-production runbook](MODEL-TO-PRODUCTION.md): verify immutable training and benchmark evidence, publish the weights, test a tagged backend and predictor at zero normal traffic, promote the default routes, release the exact tested web preview version, then retire confirmed old-model resources after live smoke. The [October 7 promotion record](IMAGINE-BASELINE-PROMOTION-20261007.md) preserves the earlier tagged rollout and its then-valid 4B rollback state as **historical evidence**, not current operating instructions.
